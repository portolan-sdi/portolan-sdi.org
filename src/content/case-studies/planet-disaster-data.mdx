*Draft · Disaster response · Satellite imagery · Source Cooperative*

[Planet](https://www.planet.com/disasterdata/) operates Earth-observation satellites. Its Crisis Response Program shares imagery to help teams respond to disasters. Those teams need suitable before-and-after scenes with clear documentation of gaps in coverage.

> "Accelerate humanitarian response with Planet imagery"
>
> — [Planet Crisis Response Program](https://www.planet.com/disasterdata/)

## One catalog, direct access

Planet publishes its [disaster releases](https://source.coop/planet/disasterdata) as a Portolan catalog on Source Cooperative. Each event brings together imagery, dates, footprints, quality masks, and documentation for people and agents.

Readers can browse the catalog or query scene indexes with DuckDB. Geospatial tools stream imagery without downloading entire scenes. Public releases need no account or API key.

## Reach so far

On 2026-11-18, the catalog covered **9 disaster events**. [Source Cooperative reported](https://source.coop/planet/disasterdata) **2.2 million downloads and 1.3 TB served across 86 countries** over 28 days. These figures measure repository traffic.

New events join the same catalog. Imagery is [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), with an OpenStreetMap waiver in the repository docs.
