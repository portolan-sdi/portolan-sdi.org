## Background

[Fields of the World](https://taylorgeospatial.org/innovation/fields-of-the-world/) brings together agricultural field-boundary research, open training data, models, and tools. Taylor Geospatial sponsors the work with research partners including Arizona State University, WashU, Ai2, and Microsoft.

Field maps support food security assessment, crop analysis, and land-use monitoring. FTW uses satellite imagery and machine learning to make those maps available where existing coverage is incomplete.

> All data, models, and code are published freely with permissible licenses on public platforms in cloud-native geospatial formats.

— [Taylor Geospatial's description of FTW](https://taylorgeospatial.org/innovation/fields-of-the-world/).

## The challenge

Producing field boundaries is only part of the work. Researchers need to find the right year and region and use the files in their own tools. The release also needs to explain how predictions were made.

FTW's [Global Data second edition](https://source.coop/ftw/global-data-2e) has yearly vector boundaries and raster probabilities spanning 2017–2025. Processing and coverage vary by year, so the documentation needs to record those differences.

## The solution

FTW publishes a Portolan catalog on Source Cooperative. [STAC](https://stacspec.org/en/) metadata organizes the years and products. [GeoParquet](https://geoparquet.org/) holds vector boundaries, [COG](https://cogeo.org/) holds raster probabilities, and [PMTiles](https://docs.protomaps.com/pmtiles/) supports web maps.

The files can be read directly from object storage. The catalog's `README.md` explains access and limitations for people, and `AGENTS.md` provides guidance for agents. The metadata and processing pipeline are maintained in the [catalog's source repository](https://github.com/fieldsoftheworld/ftw-global-data-catalog).

One publication supports several ways to use it. The [catalog browser](https://browser.portolan-sdi.org/#/external/data.source.coop/ftw/global-data-2e/catalog.json) and interactive map provide visual entry points. Readers can also [get the files](https://source.coop/ftw/global-data-2e).

## Results and impact

The published 2025 collections show the scale of this release, as checked on November 18, 2026.

- **225,519,173 predicted fields** in **60 GeoParquet files**, totaling **109.7 GiB**, in the [2025 vector collection](https://data.source.coop/ftw/global-data-2e/vector/2025/collection.json).
- **14,590 probability COGs**, totaling about **5.79 TB**, in the [2025 raster collection](https://data.source.coop/ftw/global-data-2e/raster/2025/collection.json).
