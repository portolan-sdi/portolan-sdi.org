Portolan

An opinionated standard for cloud-native geospatial catalogs

The future of spatial data is just files.

Portolan is an opinionated standard for sharing geospatial data as cloud-native files on object storage, plus the tools that make it real. A Portolan catalog is a directory of open-format data described by structured STAC metadata, hosted on any S3-compatible bucket. No servers, no databases.

Why Portolan

The job of an SDI has changed.

Open and interoperable

Everything is open source under Apache-2.0 and built on existing standards. Your data works everywhere, with or without Portolan.

Readable by people and machines

A Portolan catalog describes itself in plain text and structured metadata, so a person, a script, or an agent can query it with no bespoke API to learn.

Simple

A traditional SDI needs databases, services, and staff to run them. A Portolan catalog is files in a bucket.
